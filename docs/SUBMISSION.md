### 3. AWS Implementation

I used AWS Amplify Hosting to deploy my portfolio website.

Implementation steps:

1. Created the portfolio locally using VS Code.
2. Initialized Git in the project directory.
3. Created a GitHub repository.
4. Pushed the project source code to GitHub.
5. Connected the GitHub repository to AWS Amplify.
6. Selected the main branch.
7. Configured the frontend deployment settings.
8. Successfully deployed the portfolio.

### 4. AWS Services Used
